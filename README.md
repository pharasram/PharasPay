# PharasPay

India-focused digital lending platform. The Flutter Android/iOS app is in [`mobile/`](mobile/README.md). The Next.js customer website is in [`web/`](web/README.md).

For the local website demo, double-click `run-website.cmd` or follow the [website setup guide](web/README.md). Demo mobile: `9999999999`; OTP: `123456`.

The app includes mock lending flows, Riverpod state management, secure storage, native security templates and unit/widget tests. Current validation: 36 passing tests and 84.0% authored Dart line coverage.

See [setup and build instructions](mobile/README.md), [backend integration contract](mobile/docs/API_CONTRACT.md) and [verification report](mobile/docs/VERIFICATION.md). Production KYC, liveness, e-sign, payment and immutable audit services require authorized integrations.
